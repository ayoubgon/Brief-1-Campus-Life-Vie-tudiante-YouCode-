# 🚀 YouCode Campus Life - Web Integration Project

A professional multi-page website clone of the **YouCode** school interface, focusing on the "Campus Life" experience. This project demonstrates advanced HTML/CSS integration skills, responsive design, and attention to UI/UX details.

## ✨ Key Features
*   **Immersive Hero Section:** Capturing the essence of student life.
*   **Stats Bar:** Visual representation of campus achievements.
*   **YouCode Journey Roadmap:** A step-by-step visual guide from Day 1 to graduation.
*   **Events Section:** Organized card layout for Tech Talks and Hackathons.
*   **Detailed Campus Pages:** Showcase of training rooms, collaborative spaces, and relaxation areas.

## 🛠️ Technologies Used
*   **HTML5:** Semantic structure for better SEO and accessibility.
*   **CSS3:** Custom styling using Flexbox, Grid, and CSS variables.
*   **Remix Icons / FontAwesome:** For sleek and modern iconography.
*   **Google Fonts:** Utilizing the official typography of the brand.
